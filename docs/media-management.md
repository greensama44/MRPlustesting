# Media Management

Open **`/admin/media.html`**. It lists every image the site uses (32 site images, 143 placements across 11 pages) plus anything you upload.

## Opening it
It must be served together with the site and its API: open `https://<your-site>/admin/media.html` once this update is deployed, or run it locally with `node scripts/dev-server.mjs` and visit `http://localhost:8123/admin/media.html` (in-memory storage, resets when stopped). Opening `media.html` directly as a file cannot work and shows an explanation instead.

## What you can do
- **Replace any image everywhere:** open an item, choose *Upload replacement* (or *Choose from uploads*). Every page that uses it updates, including cards built by JavaScript, the logo, and the store photos. *All screens* or *Mobile only* can be chosen separately.
- **Restore original** puts the site's original back.
- **Background video:** attach an MP4/WebM to an image slot. It plays muted and looped behind the image, the image is the poster, and it stays a still for visitors who prefer reduced motion or have Data Saver on.
- **Upload** images (JPG, PNG, WebP, SVG) and videos (MP4, WebM). Identical files are detected by hash and never stored twice.
- **Replace an uploaded file everywhere** keeps all of its usages and swaps the file.
- **Delete** warns when an asset is in use; confirming puts the original back wherever it was used.
- **Usage:** every item shows the pages and sections/cards that use it, with a link to open the page.

## Setup
Needs a Vercel Blob store connected to the project (it provides `BLOB_READ_WRITE_TOKEN`, which the accounts API already uses). Without it the screen shows "Media storage is not configured". No other environment variables are needed.

## How it works
- `media-manifest.json` maps every image to its pages and sections (generated by `node scripts/build-media-manifest.cjs`).
- Replacements live in one private Blob document (`media/registry.json`). Uploaded files are stored in the **private** Blob store and served through `/api/media/file?id=...` (cached for a year; each file has its own id).
- `/api/content` returns the replacements. `cms.js` (loaded on every page) swaps images by their stable key (Unsplash photo ID, local `assets/...` path, or `logo`), also for images added to the page later. The HTML keeps its built-in images as the fallback, so the site looks the same if the API is down.
- Files up to 4.3 MB (images or videos) upload through the API. Larger files upload straight from the browser to Blob (up to 200 MB) and are then registered; that path needs a quick real-world test after the first deploy.
- API handlers are exported as `{ fetch }`, as Vercel requires for this project (`wrap` in `api/_lib.js`).

## After you change the code
If you add a new image (or a new page) to the HTML, run `node scripts/build-media-manifest.cjs` and commit `media-manifest.json` so it appears in the library. Images are replaceable only if they are in the manifest.

## Security (read this)
By request there is **no login** on this screen or its API. Anyone who finds `/admin/media.html` can replace your site's images and upload files. Built-in protections: same-origin and header checks, file type, size and signature validation, SVG script rejection, a rate limit, and one-click *Restore original*. These do not replace access control. **Turn on Vercel Password Protection (or Deployment Protection) for the project before launch**, or restrict `/admin` and `/api/media` another way.

## Limitations
- Replacements apply to images listed in the manifest. Unlisted images (for example a photo added later) need a manifest rebuild.
- No cropping or focal-point tool; replacement images are shown with the page's existing crop (`object-fit: cover`). Upload at the same aspect ratio for best results.
- One registry document, no locking: two people replacing at the same moment can overwrite each other.
- Videos overlay the image's box (hero and card backgrounds). They are not a separate video component.
- Deleting from the library removes the file from Blob storage; there is no recycle bin.
